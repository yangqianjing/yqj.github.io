如何使用 Markdown 写博客

Markdown 是一种轻量级标记语言，非常适合写博客。

基础语法

标题

# 一级标题
## 二级标题
### 三级标题

强调

  • 粗体：**粗体**
  • 斜体：*斜体*
  • 删除线：~~删除线~~

列表

无序列表：

  • 项目 1
  • 项目 2
  • 项目 3

有序列表：

  1. 第一步
  2. 第二步
  3. 第三步

代码

行内代码：console.log('Hello')

代码块：

function greet(name) {
  console.log(`Hello, ${name}!`);
}

链接和图片

  • 链接：[文字](https://example.com)
  • 图片：![描述](图片链接)

引用

这是一段引用文字。
可以有多行。

进阶技巧

表格

标题1 标题2 标题3
内容1 内容2 内容3
内容4 内容5 内容6

任务列表

  • ✓ 完成的任务
  • □ 未完成的任务

希望这篇教程能帮助你快速上手 Markdown 写作！
