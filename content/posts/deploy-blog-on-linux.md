## 前言

本文介绍了在 Linux 服务器上部署个人博客的几种常见方案。

## 方案一：静态站点生成器

使用 Hugo、Hexo 或 Jekyll 等静态站点生成器，具有以下优点：

- 性能极好
- 维护简单
- 成本低
- 安全性高

## 方案二：GitHub Pages

GitHub Pages 是一个完全免费的静态网站托管服务：

1. 创建仓库 `username.github.io`
2. 上传 HTML 文件
3. 自动部署

访问 `https://username.github.io` 即可看到你的博客。

## 总结

选择适合自己的方案，开始记录你的技术成长之路吧！
